# Productfoto's

Foto's die in `assets/data.js` bij een model in de `photos`-array staan, horen
in deze map. De eerste foto uit die array is de coverfoto op de kaart in het
overzicht; de rest staat in de galerij van het detailvenster, vóór de
schematische tekeningen.

Ontbreekt een bestand, dan valt die plek automatisch terug op het
vooraanzicht-tekeningetje — de pagina blijft dus heel.

## Verwacht voor Siemens KI81RNSE0

| Bestand | Inhoud |
|---|---|
| `siemens-ki81rnse0-1-open.jpg` | Volledige koelkast met open deur — **coverfoto** |
| `siemens-ki81rnse0-2-interieur.jpg` | Interieur met plateaus en deurvakken |
| `siemens-ki81rnse0-3-vershoudlades.jpg` | De twee vershoudlades met groente en fruit |
| `siemens-ki81rnse0-4-bediening.jpg` | Bedieningspaneel met PowerVentilation |
